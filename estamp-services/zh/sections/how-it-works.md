  无需排队，无需 MyTax 门户，无需奔波至区县土地局。上传一次，在线支付，

  - title: 上传您的文件
    description: >-
      一分钟内创建账户，将租约或其他符合条件的文件以 PDF 格式上传。
      系统会自动核查文件类型与合同金额，让您立即知道是否可以在线印花。
  - title: 核对并付款
    description: >-
      印花税自动为您计算——普通租约为 RM50——付款前完整显示。
      支持信用卡、FPX 网上银行或电子钱包安全支付。无订阅、无隐藏费用：
      按文件计费，印花时才付款。
  - title: 接收您的证书
    description: >-
      官方 LHDN 电子印花证书即时签发，直接发送到您的邮箱，并附有可供
      验证的唯一证书编号。下载、存档、转发给租客——自签发起在全国
      范围内即具法律效力。
