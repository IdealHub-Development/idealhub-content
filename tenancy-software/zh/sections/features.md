- icon: Building
  title: 续租与押金

- icon: LayoutDashboard
  title: 租户门户

- icon: MessageCircle
  title: 维修请求
  description: 租户附照片报告问题；工单分派给我们的团队或您自己的承包商，每次上门都有记录。

- icon: Settings
  title: 报表与业主对账单
  description: 月度对账单、欠租和收入报表 — 可导出给您的会计师或用于报税。
  note: 可导出给您的会计师或用于报税
- icon: FilePlus
  title: 租客申请
  description: 分享一个申请链接 — 申请人上传证件、工资单和推荐人信息。由您审核决定。

  title: 在线收租

  title: 文件与入住
