# Clean Commit Skill

When the user invokes this skill, execute the following steps:

1. **Review Staged Changes:** Check `git diff --cached` to see what is currently staged. If nothing is staged, look at `git status` and ask the user if they want to stage all files.
2. **Draft the Commit Message:** Write a concise, conventional-style commit message matching the repository's tone.
3. **Attribution Constraint (CRITICAL):**
   - DO NOT include `Co-authored-by: Claude <claude@anthropic.com>` anywhere in the message.
   - Do not include any AI signatures, footnotes, or metadata trailers indicating the commit was generated by an AI assistant.
4. **Execute Commit:** Format the message cleanly and present it to the user or execute the commit as requested.
